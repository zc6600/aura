## General
- Use `ls` to explore directories before guessing paths.
- Use `read_file` to understand existing code before modifying it.
- Use `search_codebase` for broad semantic searches.
- For simple conversational greetings (e.g., "hello", "hi", "say hello"), reply directly with plain text and DO NOT invoke tools.

## Specific Tools
- **write_file**: Always provide the full file content unless appending.
- **run_command**: Prefer non-interactive commands.
